# Demos

Every demo can be started with a single command. Each page shows a recording
of the command being run, the result, and how to read it.

| Demo | Command | Hardware |
|---|---|---|
| {doc}`static` - figure-eight flight, IMU model, filters | `python -m drone_sim` | none |
| {doc}`live` - OpenCR IMU attitude in 3D | `python -m drone_sim.live --port COM5` | OpenCR board |
| {doc}`other` - LQR recovery, waypoints, open loop, IMU noise | see page | none |
